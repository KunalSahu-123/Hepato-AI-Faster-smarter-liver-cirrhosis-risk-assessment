About Hepato AI

A final-year B.Tech major project: machine-learning decision support for liver cirrhosis risk, built end to end as a deployable web application.

The problem

Cirrhosis is frequently caught late. Early symptoms are vague, the diagnosis leans on a scatter of lab markers that have to be read together rather than one at a time, and biopsy — still the reference standard — is invasive enough that it is not a screening tool. The practical gap is triage: deciding quickly which patients deserve a closer look.

The approach

Hepato AI trains a Random Forest on routine markers — bilirubin, albumin, copper, alkaline phosphatase, SGOT, triglycerides, platelets, prothrombin time — alongside demographics and physical signs such as ascites, hepatomegaly, spider angiomas and oedema. The output is a calibrated probability, so 0.70 genuinely means about 70 in 100, and every score is reported with the markers that produced it.

Dataset
The bundled dataset is synthetic. It follows the schema, value ranges and marker correlations of the Mayo Clinic primary biliary cirrhosis (PBC) trial dataset, but the rows are generated (generate_dataset.py, fixed seed) rather than taken from real patients. This keeps the whole pipeline reproducible without redistributing clinical data. To train on the genuine dataset, download cirrhosis.csv from Kaggle or the UCI ML repository, drop it in at dataset/cirrhosis.csv with the same column names, and re-run python train_model.py — no code changes are needed.

Either way, histologic stage 4 is the high-risk class and stages 1–3 form the comparison group. Every figure shown on this site is measured on whichever dataset the model was last trained against.

Objectives
  • Give clinicians a fast, explainable preliminary risk screen
  • Report calibrated probabilities, not bare labels
  • Show the markers behind every individual score
  • Sit the ML output next to established scores (MELD, FIB-4, APRI, Child-Pugh)
  • Keep a per-patient history so change over time is visible
  • Produce shareable PDF and CSV reports
  • Enforce authentication, access control and audit logging throughout

Known limitations

Stating these plainly is part of the work, not a disclaimer bolted on afterwards:

  • The bundled data is synthetic. The reported accuracy therefore measures whether the pipeline learns the structure that was generated into the data — it is not evidence of clinical performance. Retraining on the real PBC dataset is a one-file swap, and the honest numbers are whatever that run produces.
  • The PBC schema itself covers a single disease aetiology from a 1970s–80s trial cohort. PBC is one cause of cirrhosis among many, so even the real dataset would not represent a general modern population.
  • The target is histologic stage 4, which is a proxy for cirrhosis rather than a direct clinical diagnosis.
  • No external validation on an independent cohort has been performed, so held-out figures are optimistic for real-world use.
  • Feature importance and leave-one-out drivers describe how the model behaves. They are not statements about causation in the patient.
  • Stage dominates the learned importance, and it is itself a histology finding — so the model leans on information that comes from the same biopsy the target is derived from. Read the marker-driven part of the explanation with that in mind.
  • Child-Pugh is computed only in part: encephalopathy grade is not among the dataset's inputs, so that component is omitted and the score is reported as partial.
Hepato AI is a decision-support tool built for academic demonstration. It does not replace clinical judgment, laboratory confirmation, or a licensed physician's diagnosis.
